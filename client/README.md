# July's Salon — Client

React + Vite frontend for the July's Salon booking platform.

Full documentation (setup, environment variables, API, architecture, deployment) is in the [root README](../README.md).

Quick start:

```powershell
cd client
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

Requires `VITE_API_BASE_URL` (see the root README) and the API running.
